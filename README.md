# Task Management Service

Welcome to the Task Management Service! 🚀

This project allows users to manage tasks efficiently with features including task creation, editing, deletion, and expiration management, all organized through a Kanban board. With a strong focus on authentication and user experience, this service ensures secure and smooth task handling.

## Features

- **Task Management**: Create, edit, and delete tasks.
- **Expiration Handling**: Set and manage task deadlines.
- **Kanban Board**: Organize tasks visually with a Kanban table.
- **Authentication**: Secure login and registration with JWT.
- **Styled UI & UX**: Intuitive and responsive design for a seamless experience.

## Getting Started

To get started with this project, follow these steps:

1. **Clone the Repository**
    ```bash
    git clone https://github.com/Haguel/Task-Management-Service
    ```

2. **Navigate to the Project Directory**
    ```bash
    cd Task-Management-Service
    ```

3. **Start the Services**
    ```bash
    docker-compose up
    ```
   This command will build and start both the frontend and backend services.

4. **Navigate to http://localhost:4200**
